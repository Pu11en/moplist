# MopList — cold email variants for Instantly

Five angles, each built on a different thing operators actually said in
r/cleaningbusiness. Run them against each other; don't guess which wins.

**Benchmark to expect** (from an operator running commercial-service campaigns):
*"2,000+ emails with a 2% reply rate, and that's turned into 16 handed-off leads."*
→ **300 emails ≈ 6 replies.** Plan for that, not for revenue.

**Copy rule from the same thread:** *"A clear offer in the first line... Vague 'we do
commercial cleaning' gets deleted."* Every variant below states the offer in line one.

---

## Rules

- **Never** claim leads are qualified, interested, or ready to buy.
- **Never** invent a conversion rate, customer count or testimonial. There are none.
- Real leads only. One wrong address on the first email and you're done with that contact.
- Update the 298/45/3/19 numbers if you re-run for a different city — keep them true.
- Honour "stop" the same day, permanently.
- Footer needs a real mailing address (CAN-SPAM).
